## Jest Demo

本仓库展示了如何使用 [Jest](https://jestjs.io/) 测试框架编写单元测试，涵盖了多种常见的测试场景和匹配器的使用。

参考学习：[Jest 文档](https://jestjs.io/zh-Hans/docs/)

## 目录说明

- **`src/`** : 包含实现的功能模块，每个文件对应一个测试场景。
- **`tests/`** : 包含与 `src/` 中模块对应的测试文件，使用 Jest 编写。

## 使用指南

### 安装依赖

确保已安装 [Node.js](https://nodejs.org/)，然后运行以下命令安装依赖：

```bash
npm install
```

### 运行测试

运行以下命令执行所有测试：

```bash
npm run test
```

或者：

```bash
npm test
```

## 测试场景

1. 基本运算: 测试简单的加法函数。
2. toBe 匹配器: 测试值的严格相等性。
3. 函数调用: 测试函数是否被调用及调用次数。
4. 函数参数: 测试函数调用时的参数。
5. 返回值: 测试函数的返回值及调用顺序。
6. 对象属性: 测试对象是否包含指定属性及其值。
7. 数组长度: 测试数组或对象的长度。
